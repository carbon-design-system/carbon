## Contributing

Colors and theme tokens are authored in JSON using the
[Design Tokens Community Group (DTCG) 2025.10 format](https://www.designtokens.org/tr/2025.10/format/).
For contribution instructions, see the [`@carbon/colors` README](/packages/colors/README.md)
and the [theme tokens README](/packages/themes/tokens/README.md).

### Colors

The IBM Design Language color palette is maintained in
[`packages/colors/tokens/colors.tokens.json`](/packages/colors/tokens/colors.tokens.json).
See the [`@carbon/colors` README](/packages/colors/README.md) for instructions on
adding or changing colors and regenerating the package outputs.

### Themes

Theme tokens are maintained in
[`packages/themes/tokens/themes`](/packages/themes/tokens/themes), with a folder
for each theme. See the [theme tokens README](/packages/themes/tokens/README.md)
for token structure, authoring values, and build instructions.
