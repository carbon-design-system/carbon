# Prototype / Build — Figma Make skill

Skill **15** from the Prototype/Build card, packaged so you can **download it**
and **run it in Figma Make**.

## Install in Cursor (optional)

Copy this folder to your skills, or unzip. Name: `prototype-build-figma-make`.

## Use in Figma Make (what you asked for)

1. Go to [figma.com/make](https://www.figma.com/make) and sign in.
2. **New** Make file.
3. Open `FIGMA-MAKE.md` and **paste the whole file** into Make’s prompt (from
   “You are an expert…” to the end).
4. Generate. Click through: Home tabs → search → results → basket → pay → You’re
   booked.
5. Human review (see `SKILL.md`).

Figma Make does not install Cursor `SKILL.md` files. **Pasting `FIGMA-MAKE.md`
is the skill.**

## If you want a generic Make (any product)

1. Fill `prompt-1-brief.txt` in ChatGPT with your wireframes.
2. Paste `prompt-2-figma-make.txt` + that brief into Figma Make.
