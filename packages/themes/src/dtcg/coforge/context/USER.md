# User

**Primary (product):** one Luma Travel persona per screen. Priority four: **P09
Halina** (disabled / assisted — research is a gate), **P14 Bernard** (near-miss,
not exclusion), **P04 Reuben** (designated planner), **P12 Jaden** (first-timer;
physical process opacity). Detail: sibling `context/luma-travel.md`.
**Anti-framings (do not design against these):**

1. Removing planning stress (planning is the pleasure)
2. Optimising destination arrival as the primary dread (the return-home airport
   is)
3. Help-seeking as an age/accessibility issue (the “needs help booking” persona
   is 18–34)
4. Simplifying for “less digitally confident” (failure is near-miss completion)
5. Improving the booking funnel for disabled travellers (abandonment fires
   before it)
6. One app for everything (tool plurality is deliberate)

**Research:** synthetic / desk research. Evidence ledger is zero. Do not invent
user quotes. No `[E-nnn]`. Define artifacts are draft; Gate A unsigned. Label
ungrounded needs `ASSUMPTION`. **Secondary:** designer or engineer composing
with this agent + Figma. Community kit instances, not detached vectors.
**A11y:** keyboard, visible focus (ink), AA contrast. Do not put coral on small
text.
