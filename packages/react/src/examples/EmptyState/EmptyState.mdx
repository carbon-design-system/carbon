## Overview

The Empty State pattern provides a recipe for communicating an empty, error, or
no-results state to users. It is used when a page, table, or container has no
content to display.

> NOTE: Patterns have multiple ways of accomplishing a user need and typically
> use a combination of components with additional design considerations. The
> pattern code we share is meant to serve as an example implementation that can
> be built and extended further.

To build this pattern, you can use the `EmptyState` component recipe from
`example/components/EmptyState.tsx` alongside:

- [DataTable](https://react.carbondesignsystem.com/?path=/docs/components-datatable)
- [Tile](https://react.carbondesignsystem.com/?path=/docs/components-tile)
- [Button](https://react.carbondesignsystem.com/?path=/docs/components-button)
- [Link](https://react.carbondesignsystem.com/?path=/docs/components-link)
