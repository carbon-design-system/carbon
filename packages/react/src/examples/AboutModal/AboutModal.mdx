## Overview

About modal is a pattern that conveys product information, including the version
number, copyright information, and license details. The about modal is triggered
by a user's action and appears on top of the main page content. It is persistent
until dismissed. The purpose of this modal should be immediately apparent to the
user, with a clear and obvious path to completion.

To build this pattern, we recommend including the following ingredients:

- [ComposedModal](https://react.carbondesignsystem.com/?path=/docs/components-composedmodal)
- [Link](https://react.carbondesignsystem.com/?path=/docs/components-link)

### With additional content

Some products may be legally required to display logos of technologies used to
build the product. These can be provided in the footer.

While the about modal supports a list of Carbon `Link` components, these should
be used to display product information and not to direct users to find help
content.
