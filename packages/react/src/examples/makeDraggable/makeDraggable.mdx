## Overview

The `makeDraggable` utility, from `@carbon/utilities`, enables an HTML element
to be draggable using either mouse or keyboard interactions. It accepts:

- `el` (required): the HTML element to move.
- `dragHandle` (optional): the HTML element that initiates the drag, for
  example a header. When omitted, the whole element is the handle.
- `focusableDragHandle` (optional): the HTML element that receives focus for
  keyboard interaction, for example a drag icon button.
- `dragStep` (optional): the distance in pixels to move with the arrow keys
  (default: 8px).
- `shiftDragStep` (optional): the distance in pixels to move with Shift + arrow
  keys (default: 32px).

`makeDraggable` returns an object with a `cleanup` function that removes the
attached event listeners, and an `init` function that re-syncs the position if
the element was moved by something other than the utility.

## Example usage

```jsx
import { makeDraggable } from '@carbon/utilities';

const draggable = makeDraggable({
  el: dialogRef.current,
  dragHandle: headerRef.current,
  focusableDragHandle: dragRef.current,
});

// Remove the event listeners when the element is unmounted.
draggable.cleanup();
```

```jsx
<Popover open={isOpen} ref={dialogRef} className="popover">
  <Button
    aria-expanded={isOpen}
    onClick={() => {
      setIsOpen(!isOpen);
    }}
  >
    Toggle
  </Button>

  <PopoverContent className="popover-content">
    <header ref={headerRef} className="popover-header popover-title">
      <Button
        kind="ghost"
        ref={dragRef}
        className="drag-icon"
        aria-describedby="drag-instructions"
      >
        <Draggable />
      </Button>
      <span id="drag-instructions" className="cds--visually-hidden">
        To pick up the draggable item, press Enter. While dragging, use the
        arrow keys to move the item. Press Enter again to leave the item in its
        new position.
      </span>
      <Button
        kind="ghost"
        onClick={() => setIsOpen(false)}
        className="close-icon"
      >
        <Close />
      </Button>
    </header>
    <p className="heading"> Available storage</p>
    <p className="popover-details">
      This server has 150 GB of block storage remaining.
    </p>
  </PopoverContent>
</Popover>
```

## Accessibility

- **Mouse:** press and hold the drag handle, then move the pointer.
- **Keyboard:** focus the `focusableDragHandle`, then press `Enter` or `Space`
  to pick up the element. Use the arrow keys to move it, or Shift + arrow keys
  to move it in larger steps. Press `Enter` or `Space` again to drop it.
- Always provide instructions for keyboard users, for example with
  `aria-describedby` pointing to visually hidden text.
- The utility dispatches `dragstart`, `dragmove` and `dragend` events on the
  element, which you can use to update labels or styles while dragging.
