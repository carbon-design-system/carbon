## Overview

The `Card` component is a flexible container for displaying related content and
actions. Cards are composed from a set of subcomponents — `Card.Header`,
`Card.Body`, `Card.Footer`, `Card.Media`, and more — that slot into a structured
layout.

```jsx
import { Card } from '@carbon/react';

function Example() {
  return (
    <Card>
      <Card.Header>
        <Card.Title>Card title</Card.Title>
      </Card.Header>
      <Card.Body>
        <p>Card body content.</p>
      </Card.Body>
      <Card.Footer>
        <Button kind="tertiary" size="md">
          Action
        </Button>
      </Card.Footer>
    </Card>
  );
}
```

## Subcomponents

| Subcomponent      | Alias              | Purpose                                                                    |
| ----------------- | ------------------ | -------------------------------------------------------------------------- |
| `CardHeader`      | `Card.Header`      | Contains title, media, and actions                                         |
| `CardBody`        | `Card.Body`        | Primary content area                                                       |
| `CardFooter`      | `Card.Footer`      | Bottom action bar                                                          |
| `CardMedia`       | `Card.Media`       | Image/video slot (aspect ratio wrapper)                                    |
| `CardHeaderMedia` | `Card.HeaderMedia` | Icon/image slot spanning the full header width above the title             |
| `CardTitleMedia`  | `Card.TitleMedia`  | Media slot to the left of the title                                        |
| `CardTitle`       | `Card.Title`       | Primary heading text; accepts `label` and `description` props for sub-text |
| `CardActions`     | `Card.Actions`     | Action button group in the header                                          |
| `CardAction`      | `Card.Action`      | Individual action wrapper (footer or header)                               |

## Density

Cards support two density variants via the `density` prop:

- **`productive`** (default) — uses `$heading-compact-02` for a compact layout
- **`expressive`** — uses `$heading-03` for a more spacious layout

## Clickable cards

A clickable card turns the entire surface into a single action target. Pass
`clickable` to enable interactive styles (hover, focus, active states) and a
built-in footer affordance with an arrow icon.

Every clickable card **must have an accessible name** via `aria-label` or
`aria-labelledby` — a `console.error` is raised at runtime if this is missing.

`Card.Footer` is not supported inside a clickable card and will render nothing.
The footer affordance is managed by the card itself.

### Action card (onClick)

Use `onClick` when the card triggers an in-page action such as opening a modal,
selecting an item, or expanding a panel.

```jsx
<Card clickable onClick={() => openModal()} aria-label="View analytics report">
  <Card.Header>
    <Card.Title>Usage report</Card.Title>
  </Card.Header>
  <Card.Body>Content</Card.Body>
</Card>
```

### Navigation card (as="a")

Use `as="a"` with `href` when the card navigates to another page. This renders a
native `<a>` element giving users right-click, Cmd+click, and screen-reader link
semantics.

```jsx
<Card clickable as="a" href="/dashboard" aria-label="Go to dashboard">
  <Card.Header>
    <Card.Title>Dashboard</Card.Title>
  </Card.Header>
  <Card.Body>Content</Card.Body>
</Card>
```

Use any router's Link component the same way:

```jsx
// React Router
<Card clickable as={Link} to="/dashboard" aria-label="Go to dashboard">
  ...
</Card>
```

### Custom footer icon

Override the default `ArrowRight` icon using `renderFooterIcon`:

```jsx
<Card
  clickable
  onClick={handleClick}
  renderFooterIcon={Launch}
  aria-label="Launch application">
  ...
</Card>
```

## Disabled state

Pass `disabled` to mute the card visually and prevent all interaction. Manually
pass `disabled` to any interactive elements inside the card (buttons, inputs)
since the card itself does not propagate the disabled state.

## Media

Use `Card.Media` with a `ratio` prop to render an aspect-ratio-constrained media
slot. Supported ratios are those accepted by the Carbon `AspectRatio` component
(`16x9`, `9x16`, `2x1`, `1x2`, `4x3`, `3x4`, `1x1`).

Place `Card.Media` inside `Card.Header` for a top-positioned image, or as a
direct child of `Card` with the `horizontal` prop for a side-by-side layout.

## Horizontal layout

Pass `horizontal` to the `Card` to render media and content side-by-side.
`Card.Media` must be a direct child of `Card` (not nested in `Card.Header`). Use
`mediaWidth` on `Card.Media` to control the media column width (default:
`33.33%`).
