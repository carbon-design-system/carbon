## Overview

User avatars are a representation of a user or group of users. They can be used
to identify a user or indicate collaborators. By default the component will
display `name` on a `order-1-cyan` background if a name exists, otherwise it
will render a user icon. `UserAvatar` allows an image of the user to be
displayed by passing in the `image` prop, and custom icons via `renderIcon`.

## Note on theming

The user avatar supports all four Carbon theme variants (white, g10, g90, and
g100). The background color and font color adapt dynamically based on the
lighter and darker themes.
