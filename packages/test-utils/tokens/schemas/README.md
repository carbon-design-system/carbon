# Design Tokens Community Group schemas

Bundled JSON Schemas for the
[DTCG 2025.10](https://www.designtokens.org/tr/2025.10/) specification, stored
here so token conformance tests run without network access.

| File                    | Source                                                     |
| ----------------------- | ---------------------------------------------------------- |
| `2025.10/format.json`   | https://www.designtokens.org/schemas/2025.10/format.json   |
| `2025.10/resolver.json` | https://www.designtokens.org/schemas/2025.10/resolver.json |

Retrieved 2026-10-01. Both files are self-contained (every `$ref` resolves
within the file) and use JSON Schema draft-07. Do not edit them; to update,
download the published files again and update this table.
