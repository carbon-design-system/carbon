# Changelog

### August 31, 2026

New border-radius tokens have been introduced for various border-radius values.
These tokens are accompanied by new visual updates made to input components such
as TextInput, NumberInput, Search and more. Updates include rounded corners, a
new gradient border, and some added margins and insets for surrounding buttons
and menus.

### August 5, 2026

A new preview `DatePicker` has been added to `@carbon/web-components` as
`<cds-preview-date-picker>`. It is built on the
[Temporal API](https://tc39.es/proposal-temporal/docs/) and a framework-agnostic
state machine shared with `@carbon/react`, replacing the Flatpickr-based
`<cds-date-picker>` implementation. Stories and documentation can be found in
the `Components/Preview/Date Picker` section of Storybook.

The preview registers distinct custom elements (`<cds-preview-date-picker>` and
`<cds-preview-date-picker-input>`). Migrating is largely a tag and import change
— see the
[migration guide](https://github.com/carbon-design-system/carbon/blob/main/packages/web-components/src/components/date-picker/next/MIGRATION.md)
for behavioral differences, notably the updated
`cds-preview-date-picker-changed` event and the removal of Flatpickr-specific
options.

We'd like feedback on
[github](https://github.com/carbon-design-system/carbon/issues/new/choose) or
any of the #carbon-\* channels on Slack on the following:

- API and attribute surface
- Behavioral differences from the Flatpickr-backed component
- Accessibility concerns
- Any blockers, issues, etc.
