## Getting started

Here's a quick example to get you started.


## Overview

The `cds-page-header` is a large family of components, composed of three zones;
the Breadcrumb, Content, and Tabs.

<Canvas className="page-header--docs-demo" of={PageHeaderStories.Default} />

## Breadcrumb

The `cds-page-header-breadcrumb` component is used to render the breadcrumb
navigation area within the Page header. It accepts `cds-breadcrumb` and
`cds-breadcrumb-item` components as children to define the breadcrumb trail.
Additionally, it has `content-actions` and` page-actions` slots, allowing for
actions, such as `cds-button` or `cds-icon-button` — alongside the breadcrumb
content.

## Content

<Canvas
  className="page-header--docs-demo"
  of={PageHeaderStories.ContentWithContextualActionsAndPageActions}
/>

The `cds-page-header-content` component defines the primary content area of the
Page header, including the title, subtitle, and any supporting text or
contextual actions. It accepts a `title` attribute to display the main heading
and has an `icon` slot to show an icon adjacent to the title. Child components
such as `cds-page-header-content-text` can be used to provide additional
descriptive text. To support use cases such as tags, `contextual-actions` slot
can be to render components beside the content. `page-actions` slot allows
integration of action buttons aligned with the content section.

```html
<cds-page-header>
  <cds-page-header-breadcrumb>...</cds-page-header-breadcrumb>
  <cds-page-header-content title="Title">
    <div slot="contextual-actions">
      <cds-tag type="blue" size="lg">Tag</cds-tag>
    </div>
    <div slot="page-actions">
      <cds-button size="md"
        >Primary action ${Add16({ slot: 'icon' })}</cds-button
      >
    </div>
    <cds-page-header-content-text subtitle="Subtitle">
      Content text.
    </cds-page-header-content-text>
  </cds-page-header-content>
</cds-page-header>
```

### Custom title content (`title` slot)

The `title` attribute on `cds-page-header-content` accepts a plain string. When
you need arbitrary content in the title position — for example a status badge
alongside the heading text — use the `title` named slot instead. When the
`title` slot is populated, the `title` attribute is ignored.

```html
<cds-page-header-content>
  <span slot="title">
    <strong>My page</strong>
    <cds-tag type="green" size="sm">Live</cds-tag>
  </span>
</cds-page-header-content>
```

### Custom breadcrumb title content (`breadcrumb-content` slot)

When the page header uses `cds-page-header-breadcrumbs-set`, the collapsed
breadcrumb bar shows the page title as a truncated text link. Use the
`breadcrumb-content` slot to replace that truncated text with custom content —
useful when the collapsed title should match a rich `title` slot rather than a
plain string.

```html
<cds-page-header-breadcrumbs-set title="My page" breadcrumbs-data="...">
  <span slot="breadcrumb-content">
    <strong>My page</strong>
    <cds-tag type="green" size="sm">Live</cds-tag>
  </span>
</cds-page-header-breadcrumbs-set>
```

### Rich subtitle content (`subtitle-content` slot)

The `subtitle` attribute on `cds-page-header-content-text` accepts a plain
string. For rich subtitle content — links, badges, or status indicators — use
the `subtitle-content` named slot. When the slot is populated it is rendered
inside the subtitle heading element in place of the `subtitle` attribute value.

```html
<cds-page-header-content-text>
  <span slot="subtitle-content">
    Version 2.4
    <cds-link href="/changelog">View changelog</cds-link>
  </span>
  Body text goes here.
</cds-page-header-content-text>
```

### Content With Hero Image

<Canvas
  className="page-header--docs-demo"
  of={PageHeaderStories.ContentWithHeroImage}
/>

When including a hero image within the Page header, the Carbon Grid classes will
need to be utilized. In addition, the `withinGrid` attribute has to be set in
the `cds-page-header-content` and `cds-page-header-breadcrumb` components.

The `cds-page-header-hero-image` component maintains a consistent aspect ratio
(3×2 on mobile/tablet, 2×1 on desktop) and automatically prevents horizontal
overflow. The image is centered within its container using flexbox, ensuring it
stays within viewport boundaries while maintaining proper aspect ratio.

You can control how the image fills the container using the `object-fit` prop:

- `cover`: Image fills container, may crop edges (default)
- `contain`: Image fits within container, may show empty space
- `fill`: Image stretches to fill container
- `none`: Image uses its natural size

```css
@use '@carbon/grid';

// Emit css-grid styles
@include grid.css-grid();
```

```html
<cds-page-header>
  <div class="cds--css-grid">
    <div class="cds--sm:col-span-4 cds--md:col-span-4 cds--lg:col-span-8 cds--css-grid-column">
      <cds-page-header-breadcrumb within-grid border=false>...</cds-page-header-breadcrumb>
      <cds-page-header-content
        within-grid
        title="Title"
        >
        ...
      </cds-page-header-content>
      </div>
      <div class="cds--sm:col-span-0 cds--md:col-span-4 cds--lg:col-span-8 cds--css-grid-column">
        <cds-page-header-hero-image object-fit="cover">
          <picture>
            <source
              srcset="..."
              media=${`(min-width: ${breakpoints.lg.width})`}
            ></source>
            <source
              srcset="..."
              media=${`(max-width: ${breakpoints.lg.width})`}
            ></source>
            <img
              src="..."
              alt="a default image"
            />
          </picture>
        </cds-page-header-hero-image>
      </div>
    </div>
  </div>
</cds-page-header>
```

**Note:** The hero image is automatically constrained to prevent horizontal
overflow. The `picture` element uses flexbox with centered alignment to ensure
the image stays within its container boundaries across all viewport sizes.

## Tabs

To render the Tabs zone, utilize the `cds-page-header-tabs` component, passing
in the `cds-tabs` and `cds-tab` components as within its `tabs` slot. Then set
up the corresponding tab panel elements outside of `cds-page-header`.

```html
<cds-page-header>
  <cds-page-header-breadcrumb>...</cds-page-header-breadcrumb>
  <cds-page-header-content> ... </cds-page-header-content>
  <cds-page-header-tabs>
    <cds-tabs slot="tabs" value="tab-1">
      <cds-tab id="tab-1" target="tab-panel-1" value="tab-1">Tab 1</cds-tab>
      <cds-tab id="tab-2" target="tab-panel-2" value="tab-2">Tab 2</cds-tab>
    </cds-tabs>
  </cds-page-header-tabs>
</cds-page-header>
<div id="tab-panel-1" role="tabpanel" aria-labelledby="tab-1" hidden>
  Tab Panel 1
</div>
<div id="tab-panel-2" role="tabpanel" aria-labelledby="tab-2" hidden>
  Tab Panel 2
</div>
```

## Custom events

`cds-page-header` dispatches the following custom events when scroll state
changes. All events bubble and are composed.

| Event                                     | Detail                               | Description                                                                                                                                                            |
| ----------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cds-page-header-fully-collapsed`         | `{ fullyCollapsed: boolean }`        | Fired when the page header content scrolls fully out of view (`true`) or back into view (`false`). Equivalent to the React `onContentFullyCollapsed` prop.             |
| `cds-page-header-title-clipped`           | `{ titleClipped: boolean }`          | Fired when the page header title is clipped by the viewport (`true`) or becomes visible again (`false`). Equivalent to the React `onTitleClipped` prop.                |
| `cds-page-header-content-actions-clipped` | `{ contentActionsClipped: boolean }` | Fired when the page actions area is clipped by the breadcrumb bar (`true`) or becomes visible again (`false`). Equivalent to the React `onContentActionsClipped` prop. |

```javascript
document
  .querySelector('cds-page-header')
  .addEventListener('cds-page-header-fully-collapsed', (event) => {
    console.log('fully collapsed:', event.detail.fullyCollapsed);
  });
```
