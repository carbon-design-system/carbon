## Overview

The `cds-card` component is a composable container built from ten custom
elements. The root `cds-card` element owns layout and interactivity while child
elements handle each visual region.

<Canvas of={CardStories.Default} />

## Clickable

A clickable card makes the entire surface interactive. Set `aria-label` or
`aria-labelledby` to provide an accessible name. When `href` is set the card
renders as an `<a>` element; otherwise it uses `role="button"` with full
keyboard support (Enter / Space).

## With Header Actions

Place `cds-card-actions` in the `actions` slot of `cds-card-header`. The actions
sit end-aligned in the header and the title fills all remaining space, with no
JavaScript measurement. The actions slot is capped at 50% of the header; items
that do not fit collapse into a `cds-overflow-menu`, and selecting a menu item
triggers the original button. Labels for the menu are resolved from the
`cds-card-action` `label`, then the button's `label`, `aria-label`, `title` or
text content.

```html
<cds-card-header>
  <cds-card-title>Title</cds-card-title>
  <cds-card-actions slot="actions">
    <cds-card-action label="Edit">…</cds-card-action>
  </cds-card-actions>
</cds-card-header>
```

<Canvas of={CardStories.WithHeaderActions} />

## With Header Media

Place an icon, avatar, tag or image in the `header-media` slot of
`cds-card-header`. It renders in a row above the title, sharing that row with
any actions; the title drops to a full-width second row. The standalone
`cds-card-header-media` element is still exported for backward compatibility.

```html
<cds-card-header>
  <cds-tag slot="header-media">New</cds-tag>
  <cds-card-title>Title</cds-card-title>
</cds-card-header>
```

<Canvas of={CardStories.WithHeaderMedia} />

## With Horizontal Media

Set `horizontal` on `cds-card`. `cds-card-media` will self-assign to the `media`
slot and the card renders a flex row layout. Use `media-position="end"` to move
media to the right.

## With Title Media

Place a media element in the `title-media` slot of `cds-card-title` to render it
to the left of the title text block. The standalone `cds-card-title-media`
element is still exported for backward compatibility.

```html
<cds-card-title>
  <img slot="title-media" src="…" alt="" />
  Title
</cds-card-title>
```
