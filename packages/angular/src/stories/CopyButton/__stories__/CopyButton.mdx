## Overview

The copy button should be accompanied by a tooltip. Tooltip feedback text should
be concise and describe the action taken when the user clicks the copy button.
By default we display the text “Copied!”.

### Importing

```ts
import { CopyButtonComponent } from '@carbon/angular/copy-button';

@Component({
  standalone: true,
  imports: [CopyButtonComponent],
  template: `
    <cds-ng-copy-button feedback="Copied!" (click)="onCopy($event)">
      Copy to clipboard
    </cds-ng-copy-button>
  `,
})
export class MyComponent {
  onCopy(event: MouseEvent) {
    /* ... */
  }
}
```

## Angular-specific notes

- **Component import:**
  `import { CopyButtonComponent } from '@carbon/angular/copy-button'` (use in
  standalone `imports: [CopyButtonComponent]` or `NgModule` `imports`)
- The host element in DevTools will be `cds-ng-copy-button` — this is the web
  component running under a prefixed tag (ADR 0020). There is no inner element.
- The projected text content is used as the icon description read by screen
  readers.
- Inputs use camelCase property bindings, for example `[feedbackTimeout]="2000"`
  and `[autoAlign]="true"`.
- `cds-ng-copy-button` has no custom click event. Bind the native `click` event
  with `(click)="handler($event)"`.
