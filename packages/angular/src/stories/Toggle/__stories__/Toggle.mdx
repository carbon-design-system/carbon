## Overview

A toggle is used to quickly switch between two possible states. They are
commonly used for "on/off" switches.

### Importing

```ts
import {
  ToggleComponent,
  ToggleSkeletonComponent,
} from '@carbon/angular/toggle';

@Component({
  standalone: true,
  imports: [ToggleComponent],
  template: `
    <cds-ng-toggle
      labelText="Airplane mode"
      labelA="On"
      labelB="Off"
      [toggled]="true"></cds-ng-toggle>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms Integration (`ControlValueAccessor`)

`ToggleComponent` implements `ControlValueAccessor`, allowing two-way boolean
binding via `[(ngModel)]` or `[formControl]`:

```html
<cds-ng-toggle
  labelText="Notifications"
  [(ngModel)]="notificationsEnabled"></cds-ng-toggle>
```
