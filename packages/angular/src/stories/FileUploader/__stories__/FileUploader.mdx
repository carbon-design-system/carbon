## Overview

The `cds-ng-file-uploader` component lets users select one or more files to
upload. It is composed with either a `cds-ng-file-uploader-button` or a
`cds-ng-file-uploader-drop-container`, and lists the selected files with
`cds-ng-file-uploader-item`.

### Importing

```ts
import {
  FileUploaderComponent,
  FileUploaderButtonComponent,
  FileUploaderDropContainerComponent,
  FileUploaderItemComponent,
} from '@carbon/angular/file-uploader';

@Component({
  standalone: true,
  imports: [FileUploaderComponent, FileUploaderButtonComponent],
  template: `
    <cds-ng-file-uploader
      labelTitle="Upload files"
      labelDescription="Max file size is 500kb. Only .jpg files are supported.">
      <cds-ng-file-uploader-button
        buttonKind="primary"
        accept="image/jpeg"
        (fileUploaderButtonChanged)="onChange($event)">
        Add file
      </cds-ng-file-uploader-button>
    </cds-ng-file-uploader>
  `,
})
export class MyComponent {
  onChange(event: CustomEvent) {}
}
```

## Angular-specific notes

### Events

The wrappers expose the web component custom events as outputs:

| Component                             | Output                             | Web component event                        |
| ------------------------------------- | ---------------------------------- | ------------------------------------------ |
| `cds-ng-file-uploader-button`         | `fileUploaderButtonChanged`        | `cds-file-uploader-button-changed`         |
| `cds-ng-file-uploader-drop-container` | `fileUploaderDropContainerChanged` | `cds-file-uploader-drop-container-changed` |
| `cds-ng-file-uploader-item`           | `fileUploaderItemBeingdeleted`     | `cds-file-uploader-item-beingdeleted`      |
| `cds-ng-file-uploader-item`           | `fileUploaderItemDeleted`          | `cds-file-uploader-item-deleted`           |

```html
<cds-ng-file-uploader-button
  (fileUploaderButtonChanged)="onChange($event)"></cds-ng-file-uploader-button>
```
