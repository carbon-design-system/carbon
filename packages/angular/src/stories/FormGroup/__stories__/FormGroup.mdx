## Overview

`cds-ng-form-group` groups related form controls inside a `<fieldset>` with a
`<legend>`. It can also show a group-level message and invalid state.

### Importing

```ts
import { FormGroupComponent } from '@carbon/angular/form-group';
import { FormItemComponent } from '@carbon/angular/form';
import { TextInputComponent } from '@carbon/angular/text-input';

@Component({
  standalone: true,
  imports: [FormGroupComponent, FormItemComponent, TextInputComponent],
  template: `
    <cds-ng-form-group legendText="Contact">
      <cds-ng-form-item>
        <cds-ng-text-input label="First name"></cds-ng-text-input>
      </cds-ng-form-item>
    </cds-ng-form-group>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

- **Component imports:** `FormGroupComponent` comes from
  `@carbon/angular/form-group`. `FormItemComponent` comes from
  `@carbon/angular/form`.
- **Date picker:** the web components `With AI label` story uses the classic
  `cds-date-picker`. `@carbon/angular` only wraps the Preview Date Picker (see
  [ADR 0021](https://github.com/carbon-design-system/carbon/blob/main/docs/decisions/0021-angular-drop-classic-date-picker.md)),
  so the Angular story uses `cds-ng-preview-date-picker` with `kind="single"`.
