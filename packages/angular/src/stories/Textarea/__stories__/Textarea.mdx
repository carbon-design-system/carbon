## Overview

The `cds-ng-textarea` component allows users to enter multiline text. It
supports character/word counters, validation states, helper text, and AI labels.

### Importing

```ts
import { TextareaComponent } from '@carbon/angular/textarea';

@Component({
  standalone: true,
  imports: [TextareaComponent],
  template: `
    <cds-ng-textarea
      label="TextArea label"
      helperText="TextArea helper text"
      placeholder="Placeholder text"></cds-ng-textarea>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`TextareaComponent` implements `ControlValueAccessor`, enabling seamless two-way
binding via reactive forms or template-driven forms:

```html
<!-- Reactive forms -->
<cds-ng-textarea
  [formControl]="descriptionControl"
  label="Description"></cds-ng-textarea>

<!-- Template-driven forms -->
<cds-ng-textarea
  [(ngModel)]="description"
  label="Description"></cds-ng-textarea>
```
