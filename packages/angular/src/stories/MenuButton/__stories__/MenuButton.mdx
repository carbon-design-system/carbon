## Overview

A `cds-ng-menu-button` can be used to group a set of actions that are related.
These actions must be `cds-ng-menu-item` elements passed as children of a
`cds-ng-menu`. The trigger button's label is passed as `label`.

### Importing

```ts
import { MenuButtonComponent } from '@carbon/angular/menu-button';
import { MenuComponent, MenuItemComponent } from '@carbon/angular/menu';

@Component({
  standalone: true,
  imports: [MenuButtonComponent, MenuComponent, MenuItemComponent],
  template: `
    <cds-ng-menu-button label="Actions" kind="primary" size="lg">
      <cds-ng-menu>
        <cds-ng-menu-item label="First action"></cds-ng-menu-item>
        <cds-ng-menu-item label="Second action"></cds-ng-menu-item>
        <cds-ng-menu-item label="Third action" disabled></cds-ng-menu-item>
      </cds-ng-menu>
    </cds-ng-menu-button>
  `,
})
export class MyComponent {}
```

## Menu Alignment

The `menuAlignment` input enables you to define the placement of the menu in
relation to the menu button. For instance, setting `menuAlignment="top"` on the
menu button will render the menu above the button.

If it seems your specified `menuAlignment` isn't working, it's because we
prioritize ensuring the menu remains visible. We calculate the optimal position
to display the menu in case the provided `menuAlignment` obscures it.

We encourage you to play around in the Storybook Default stories to better
understand the `menuAlignment` input.

## Angular-specific notes

- Import `MenuButtonComponent` from `@carbon/angular/menu-button`, and
  `MenuComponent` / `MenuItemComponent` (plus `MenuItemDividerComponent` and
  `MenuItemGroupComponent` where used) from `@carbon/angular/menu`.
- Inputs are forwarded to the web component as properties, so use camelCase
  property bindings such as `[menuAlignment]`, `[menuBackgroundToken]` and
  `[menuBorder]`.
- Icons are passed to a menu item with `slot="render-icon"`.
