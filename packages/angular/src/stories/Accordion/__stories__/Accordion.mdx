## Overview

The accordion component delivers large amounts of content in a small space
through progressive disclosure. The user gets key details about the underlying
content and can choose to expand to view the full content. Each accordion item
can be opened or closed independently.

### Importing

```ts
import {
  AccordionComponent,
  AccordionItemComponent,
} from '@carbon/angular/accordion';

@Component({
  standalone: true,
  imports: [AccordionComponent, AccordionItemComponent],
  template: `
    <cds-ng-accordion size="md">
      <cds-ng-accordion-item title="Choose your plan">
        Compare plan features and select the option that best matches your
        team's expected usage.
      </cds-ng-accordion-item>
      <cds-ng-accordion-item title="Add team members">
        Invite collaborators by email and assign their workspace roles before
        launch.
      </cds-ng-accordion-item>
    </cds-ng-accordion>
  `,
})
export class MyComponent {}
```

## Component API

<ArgTypes of={AccordionStories.Default} />

### `alignment`

Controls whether the chevron and title align to the `start` (left) or `END`
(right, default). `isFlush` does not apply when `alignment="start"`.

```html
<cds-ng-accordion alignment="start">…</cds-ng-accordion>
<cds-ng-accordion alignment="END">…</cds-ng-accordion>
```

### `size`

Controls the height of each accordion heading row. Accepted values are `sm`,
`md` (default), and `lg`.

```html
<cds-ng-accordion size="sm">…</cds-ng-accordion>
<cds-ng-accordion size="md">…</cds-ng-accordion>
<cds-ng-accordion size="lg">…</cds-ng-accordion>
```

### `isFlush`

When `true`, removes the side padding so the accordion sits flush with the
container edge. Does not apply when `alignment="start"`.

```html
<cds-ng-accordion [isFlush]="true">…</cds-ng-accordion>
```

### `disabled`

Disables all accordion items at once.

```html
<cds-ng-accordion [disabled]="true">…</cds-ng-accordion>
```

## Angular-specific notes

- Import `AccordionComponent` **and** `AccordionItemComponent` — both must be in
  `imports`. The item component provides the `cds-ng-accordion-item` selector.
- Listen to `(accordionItemToggled)` on `cds-ng-accordion-item` for open/close
  events. The payload is the native `CustomEvent`.
- The `controlled` attribute on an item suppresses the built-in toggle so
  external state can drive open/close via `[open]="isOpen"`.
