## Overview

The `cds-ng-shape-indicator` component communicates status using a shape, color
and label.

### Importing

```ts
import { ShapeIndicatorComponent } from '@carbon/angular/shape-indicator';

@Component({
  standalone: true,
  imports: [ShapeIndicatorComponent],
  template: `
    <cds-ng-shape-indicator
      kind="failed"
      label="Failed"></cds-ng-shape-indicator>
  `,
})
export class MyComponent {}
```

## Kind

Shape indicators can take the form of failed, critical, high, medium, low,
cautious, undefined, stable, informative, incomplete, and draft.

## Size

Shape indicators have two text size options 12 and 14. The default is 12.

## Compact mode

When the `compact` input is set to `true`, the shape indicator displays only the
shape with the label shown in a tooltip on hover/focus. This is useful when
space is limited or when you want to display multiple indicators in a space
constrained layout.

```html
<cds-ng-shape-indicator
  kind="failed"
  label="Failed"
  [compact]="true"></cds-ng-shape-indicator>
```

## Customizing the label

You can set a string to customize the label of the Shape indicator.

## Angular-specific notes

### Input names

Web component attributes are exposed as camelCase inputs on
`ShapeIndicatorComponent`, for example `shape-description` is bound as
`[shapeDescription]` and `text-size` as `[textSize]`.
