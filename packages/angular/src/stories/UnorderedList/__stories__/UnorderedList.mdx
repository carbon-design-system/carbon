## Overview

Lists are vertical groupings of related content. `cds-ng-unordered-list` renders
a bulleted list of `cds-ng-list-item` children.

### Importing

```ts
import {
  ListItemComponent,
  UnorderedListComponent,
} from '@carbon/angular/list';

@Component({
  standalone: true,
  imports: [UnorderedListComponent, ListItemComponent],
  template: `
    <cds-ng-unordered-list>
      <cds-ng-list-item>Review pull requests</cds-ng-list-item>
      <cds-ng-list-item>Update dependencies</cds-ng-list-item>
    </cds-ng-unordered-list>
  `,
})
export class MyComponent {}
```

## Nested unordered list

Place a `cds-ng-unordered-list` inside a `cds-ng-list-item` to nest it, and set
`nested` on the child list.

<ArgTypes of={UnorderedListStories.Default} />

### `cds-ng-list-item`

| Input    | Type      | Description                                                                                                                    |
| -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `nested` | `boolean` | `true` if this list item is a child of a nested list. The ordered and unordered list set this automatically on their children. |
