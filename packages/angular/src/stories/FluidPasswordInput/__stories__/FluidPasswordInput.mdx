## Overview

The `cds-ng-fluid-password-input` component provides a fluid variant of the
password input with built-in visibility toggle.

### Importing

```ts
import { FluidPasswordInputComponent } from '@carbon/angular/fluid-password-input';

@Component({
  standalone: true,
  imports: [FluidPasswordInputComponent],
  template: `
    <cds-ng-fluid-password-input label="Password" placeholder="Enter password">
    </cds-ng-fluid-password-input>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidPasswordInputComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-password-input [formControl]="passwordControl" label="Password">
</cds-ng-fluid-password-input>

<!-- Template-driven forms -->
<cds-ng-fluid-password-input [(ngModel)]="password" label="Password">
</cds-ng-fluid-password-input>
```
