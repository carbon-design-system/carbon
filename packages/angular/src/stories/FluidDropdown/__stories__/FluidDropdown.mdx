## Overview

The `cds-ng-fluid-dropdown` component is a fluid variant of the Dropdown,
spanning the full width of its container with specialized styling.

### Importing

```ts
import {
  FluidDropdownComponent,
  FluidDropdownSkeletonComponent,
} from '@carbon/angular/fluid-dropdown';
import { DropdownItemComponent } from '@carbon/angular/dropdown';

@Component({
  standalone: true,
  imports: [FluidDropdownComponent, DropdownItemComponent],
  template: `
    <cds-ng-fluid-dropdown titleText="Label" label="Choose an option">
      <cds-ng-dropdown-item value="option-0">Option 0</cds-ng-dropdown-item>
      <cds-ng-dropdown-item value="option-1">Option 1</cds-ng-dropdown-item>
    </cds-ng-fluid-dropdown>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidDropdownComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-dropdown [formControl]="dropdownControl" titleText="Dropdown">
  <cds-ng-dropdown-item value="opt-1">Option 1</cds-ng-dropdown-item>
</cds-ng-fluid-dropdown>

<!-- Template-driven forms -->
<cds-ng-fluid-dropdown [(ngModel)]="selectedValue" titleText="Dropdown">
  <cds-ng-dropdown-item value="opt-1">Option 1</cds-ng-dropdown-item>
</cds-ng-fluid-dropdown>
```
