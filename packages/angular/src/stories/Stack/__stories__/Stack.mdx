## Overview

The Stack component is a useful layout utility in a component-based model. This
allows components to not use margin and instead delegate the responsibility of
positioning and layout to parent components.

In the case of the Stack component, it uses the spacing scale from the Design
Language in order to determine how much space there should be between items
rendered by the Stack component. It also supports a custom gap prop which will
allow a user to provide a custom value for the gap of the layout.

This component supports both horizontal and vertical orientations.

Inspiration for this component:

- https://paste.twilio.design/layout/stack/
- https://github.com/Workday/canvas-kit/blob/f2f599654876700f483a1d8c5de82a41315c76f1/modules/labs-react/layout/lib/Stack.tsx

### Importing

```ts
import { StackComponent } from '@carbon/angular/stack';

@Component({
  standalone: true,
  imports: [StackComponent],
  template: `
    <cds-ng-stack gap="6" orientation="vertical">
      <div>Item 1</div>
      <div>Item 2</div>
      <div>Item 3</div>
    </cds-ng-stack>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

- The selector is `cds-ng-stack`. Use `useCustomGapValue` (camelCase) to turn on
  custom gap values such as `gap="2rem"`:

```html
<cds-ng-stack gap="2rem" [useCustomGapValue]="true">
  <div>Item 1</div>
  <div>Item 2</div>
</cds-ng-stack>
```
