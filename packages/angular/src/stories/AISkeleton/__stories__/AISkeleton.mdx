## Overview

AI Skeleton components are loading placeholders that use the AI visual treatment
while AI-generated content is being prepared.

### Importing

```ts
import {
  AiSkeletonIconComponent,
  AiSkeletonPlaceholderComponent,
  AiSkeletonTextComponent,
} from '@carbon/angular/ai-skeleton';

@Component({
  standalone: true,
  imports: [AiSkeletonTextComponent],
  template: `<cds-ng-ai-skeleton-text
    [paragraph]="true"></cds-ng-ai-skeleton-text>`,
})
export class MyComponent {}
```

## Component API

### `cds-ng-ai-skeleton-icon`

| Input          | Type     | Description                                  |
| -------------- | -------- | -------------------------------------------- |
| `customStyles` | `string` | Custom styles to apply to the skeleton icon. |

### `cds-ng-ai-skeleton-placeholder`

This component has no inputs.

### `cds-ng-ai-skeleton-text`

<ArgTypes of={AISkeletonStories.AISkeletonText} />

## Angular-specific notes

- Selectors are `cds-ng-ai-skeleton-icon`, `cds-ng-ai-skeleton-placeholder`, and
  `cds-ng-ai-skeleton-text`.
- Inputs are forwarded to the underlying web component as properties, so use
  property bindings (`[lineCount]`, `[paragraph]`) for dynamic values.
