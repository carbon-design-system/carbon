## Overview

The `cds-ng-fluid-text-input` component provides a fluid variant of the text
input, spanning the full width of its container with specialized styling.

### Importing

```ts
import {
  FluidTextInputComponent,
  FluidTextInputSkeletonComponent,
} from '@carbon/angular/fluid-text-input';

@Component({
  standalone: true,
  imports: [FluidTextInputComponent],
  template: `
    <cds-ng-fluid-text-input label="Label" placeholder="Placeholder text">
    </cds-ng-fluid-text-input>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidTextInputComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-text-input [formControl]="textControl" label="Name">
</cds-ng-fluid-text-input>

<!-- Template-driven forms -->
<cds-ng-fluid-text-input [(ngModel)]="name" label="Name">
</cds-ng-fluid-text-input>
```
