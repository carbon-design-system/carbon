## Overview

The `cds-ng-content-switcher` component lets users toggle between two or more
content views within the same context.

### Importing

```ts
import {
  ContentSwitcherComponent,
  ContentSwitcherItemComponent,
} from '@carbon/angular/content-switcher';

@Component({
  standalone: true,
  imports: [ContentSwitcherComponent, ContentSwitcherItemComponent],
  template: `
    <cds-ng-content-switcher
      [selectedIndex]="0"
      (contentSwitcherSelected)="onSelected($event.detail)">
      <cds-ng-content-switcher-item value="all">
        First section
      </cds-ng-content-switcher-item>
      <cds-ng-content-switcher-item value="cloudFoundry">
        Second section
      </cds-ng-content-switcher-item>
    </cds-ng-content-switcher>
  `,
})
export class MyComponent {
  onSelected(detail: unknown) {}
}
```

## Angular-specific notes

### Events

`ContentSwitcherComponent` exposes the web component custom events as outputs.
The selected item is available on `event.detail`:

| Output                         | Web component event                  |
| ------------------------------ | ------------------------------------ |
| `contentSwitcherBeingselected` | `cds-content-switcher-beingselected` |
| `contentSwitcherSelected`      | `cds-content-switcher-selected`      |

```html
<cds-ng-content-switcher (contentSwitcherSelected)="onSelected($event.detail)">
  ...
</cds-ng-content-switcher>
```
