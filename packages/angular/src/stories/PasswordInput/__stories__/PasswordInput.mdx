## Overview

The `cds-ng-password-input` component provides a single-line text input field
specifically designed for entering sensitive information such as passwords,
including a toggle button to show or hide the entered characters.

### Importing

```ts
import { PasswordInputComponent } from '@carbon/angular/password-input';

@Component({
  standalone: true,
  imports: [PasswordInputComponent],
  template: `
    <cds-ng-password-input
      label="Password"
      helperText="Use at least 8 characters"
      placeholder="Enter your password">
    </cds-ng-password-input>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`PasswordInputComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-password-input [formControl]="passwordControl" label="Password">
</cds-ng-password-input>

<!-- Template-driven forms -->
<cds-ng-password-input [(ngModel)]="password" label="Password">
</cds-ng-password-input>
```
