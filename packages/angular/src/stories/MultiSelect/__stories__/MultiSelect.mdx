## Overview

The `cds-ng-multi-select` component lets users select several options from a
list.

### Importing

```ts
import {
  MultiSelectComponent,
  MultiSelectItemComponent,
} from '@carbon/angular/multi-select';

@Component({
  standalone: true,
  imports: [MultiSelectComponent, MultiSelectItemComponent],
  template: `
    <cds-ng-multi-select titleText="Label" label="Choose options">
      <cds-ng-multi-select-item value="a">Option 1</cds-ng-multi-select-item>
      <cds-ng-multi-select-item value="b">Option 2</cds-ng-multi-select-item>
    </cds-ng-multi-select>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Events

The generated wrapper exposes the web component's custom events as outputs:

| Output                       | Web component event                 |
| ---------------------------- | ----------------------------------- |
| `(multiSelectBeingselected)` | `cds-ng-multi-select-beingselected` |
| `(multiSelectSelected)`      | `cds-ng-multi-select-selected`      |
| `(multiSelectBeingtoggled)`  | `cds-ng-multi-select-beingtoggled`  |
| `(multiSelectToggled)`       | `cds-ng-multi-select-toggled`       |

### Forms integration (`ControlValueAccessor`)

`MultiSelectComponent` implements `ControlValueAccessor`. The value is a
comma-separated string of the selected item values:

```html
<!-- Reactive forms -->
<cds-ng-multi-select [formControl]="rolesControl" titleText="Roles">
  <cds-ng-multi-select-item value="editor">Editor</cds-ng-multi-select-item>
  <cds-ng-multi-select-item value="owner">Owner</cds-ng-multi-select-item>
</cds-ng-multi-select>

<!-- Template-driven forms -->
<cds-ng-multi-select [(ngModel)]="roles" titleText="Roles">
  <cds-ng-multi-select-item value="editor">Editor</cds-ng-multi-select-item>
  <cds-ng-multi-select-item value="owner">Owner</cds-ng-multi-select-item>
</cds-ng-multi-select>
```
