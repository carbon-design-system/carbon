## Overview

The `cds-ng-combo-box` component lets users select an option from a list, or
filter the list by typing into the input.

### Importing

```ts
import {
  ComboBoxComponent,
  ComboBoxItemComponent,
} from '@carbon/angular/combo-box';

@Component({
  standalone: true,
  imports: [ComboBoxComponent, ComboBoxItemComponent],
  template: `
    <cds-ng-combo-box titleText="Label" helperText="Helper text">
      <cds-ng-combo-box-item value="option-1">Option 1</cds-ng-combo-box-item>
      <cds-ng-combo-box-item value="option-2">Option 2</cds-ng-combo-box-item>
    </cds-ng-combo-box>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Events

The generated wrapper exposes the web component's custom events as outputs:

| Output                    | Web component event              |
| ------------------------- | -------------------------------- |
| `(comboBoxBeingselected)` | `cds-ng-combo-box-beingselected` |
| `(comboBoxSelected)`      | `cds-ng-combo-box-selected`      |
| `(comboBoxBeingtoggled)`  | `cds-ng-combo-box-beingtoggled`  |
| `(comboBoxToggled)`       | `cds-ng-combo-box-toggled`       |

### Forms integration (`ControlValueAccessor`)

`ComboBoxComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-combo-box [formControl]="fruitControl" titleText="Fruit">
  <cds-ng-combo-box-item value="apple">Apple</cds-ng-combo-box-item>
  <cds-ng-combo-box-item value="banana">Banana</cds-ng-combo-box-item>
</cds-ng-combo-box>

<!-- Template-driven forms -->
<cds-ng-combo-box [(ngModel)]="fruit" titleText="Fruit">
  <cds-ng-combo-box-item value="apple">Apple</cds-ng-combo-box-item>
  <cds-ng-combo-box-item value="banana">Banana</cds-ng-combo-box-item>
</cds-ng-combo-box>
```
