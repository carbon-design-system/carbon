## Overview

The `cds-ng-number-input` component allows users to enter numeric values. It
supports stepping, min/max bounds, empty state handling, locale formatting, and
AI labels.

### Importing

```ts
import { NumberInputComponent } from '@carbon/angular/number-input';

@Component({
  standalone: true,
  imports: [NumberInputComponent],
  template: `
    <cds-ng-number-input
      label="NumberInput label"
      helperText="Optional helper text"
      [min]="0"
      [max]="100"
      [step]="1"
      [value]="50"></cds-ng-number-input>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`NumberInputComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-number-input
  [formControl]="quantityControl"
  label="Quantity"></cds-ng-number-input>

<!-- Template-driven forms -->
<cds-ng-number-input
  [(ngModel)]="quantity"
  label="Quantity"></cds-ng-number-input>
```
