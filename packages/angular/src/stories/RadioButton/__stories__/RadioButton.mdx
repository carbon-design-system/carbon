## Overview

Use radio buttons when the user needs to select only one option from a
predefined set of mutually exclusive choices.

### Importing

```ts
import {
  RadioButtonComponent,
  RadioButtonGroupComponent,
  RadioButtonSkeletonComponent,
} from '@carbon/angular/radio-button';

@Component({
  standalone: true,
  imports: [RadioButtonComponent, RadioButtonGroupComponent],
  template: `
    <cds-ng-radio-button-group
      legendText="Radio Button group"
      name="radio-group"
      value="radio-1">
      <cds-ng-radio-button
        labelText="Option 1"
        value="radio-1"></cds-ng-radio-button>
      <cds-ng-radio-button
        labelText="Option 2"
        value="radio-2"></cds-ng-radio-button>
    </cds-ng-radio-button-group>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms Integration (`ControlValueAccessor`)

`RadioButtonGroupComponent` implements `ControlValueAccessor`, allowing two-way
binding via `[(ngModel)]` or `[formControl]`:

```html
<cds-ng-radio-button-group
  name="plan-selection"
  legendText="Select a Plan"
  [(ngModel)]="selectedPlan">
  <cds-ng-radio-button labelText="Basic" value="basic"></cds-ng-radio-button>
  <cds-ng-radio-button labelText="Pro" value="pro"></cds-ng-radio-button>
  <cds-ng-radio-button
    labelText="Enterprise"
    value="enterprise"></cds-ng-radio-button>
</cds-ng-radio-button-group>
```
