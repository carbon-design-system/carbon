## Overview

The `cds-ng-search` component enables users to find specific data or items. It
supports clear buttons, custom placeholder text, sizes, and an expandable mode.

### Importing

```ts
import { SearchComponent } from '@carbon/angular/search';

@Component({
  standalone: true,
  imports: [SearchComponent],
  template: `
    <cds-ng-search
      labelText="Search"
      placeholder="Search something..."></cds-ng-search>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`SearchComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-search [formControl]="searchQuery" labelText="Search"></cds-ng-search>

<!-- Template-driven forms -->
<cds-ng-search [(ngModel)]="query" labelText="Search"></cds-ng-search>
```
