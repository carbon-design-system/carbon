## Overview

The `cds-ng-icon` component can render icons both from JavaScript imports, as
well as inline SVG elements.

### Importing

```ts
import { IconComponent } from '@carbon/angular/icon';
import Add16 from '@carbon/icons/es/add/16.js';

@Component({
  standalone: true,
  imports: [IconComponent],
  template: ` <cds-ng-icon [icon]="add" [size]="16"></cds-ng-icon> `,
})
export class MyComponent {
  add = Add16;
}
```

## Angular-specific notes

### Passing icons

The `icon` input accepts an icon descriptor imported from `@carbon/icons`.
Assign the import to a component property and bind it with `[icon]`:

```html
<cds-ng-icon [icon]="add" [size]="16" ariaLabel="Add item"></cds-ng-icon>
```
