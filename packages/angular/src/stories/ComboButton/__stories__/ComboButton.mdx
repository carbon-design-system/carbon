## Overview

A `cds-ng-combo-button` can be used to offer additional, secondary actions in a
disclosed list next to the primary action. These additional actions must be
`cds-ng-menu-item` elements passed as children of a `cds-ng-menu`. The primary
action's label is passed as `label`.

### Importing

```ts
import { ComboButtonComponent } from '@carbon/angular/combo-button';
import { MenuComponent, MenuItemComponent } from '@carbon/angular/menu';

@Component({
  standalone: true,
  imports: [ComboButtonComponent, MenuComponent, MenuItemComponent],
  template: `
    <cds-ng-combo-button label="Primary action" [onClick]="onPrimaryAction">
      <cds-ng-menu>
        <cds-ng-menu-item label="Second action"></cds-ng-menu-item>
        <cds-ng-menu-item label="Third action"></cds-ng-menu-item>
        <cds-ng-menu-item label="Fourth action"></cds-ng-menu-item>
      </cds-ng-menu>
    </cds-ng-combo-button>
  `,
})
export class MyComponent {
  onPrimaryAction = () => {
    /* ... */
  };
}
```

## Menu Alignment (experimental)

The `menuAlignment` input enables you to define the placement of the menu in
relation to the `cds-ng-combo-button`. For instance, setting
`menuAlignment="top"` on the `cds-ng-combo-button` will render the menu above
the button.

If it seems your specified `menuAlignment` isn't working, it's because we
prioritize ensuring the menu remains visible. We calculate the optimal position
to display the menu in case the provided `menuAlignment` obscures it.

We encourage you to play around in the Storybook Default stories to better
understand the `menuAlignment` input.

## Angular-specific notes

- Import `ComboButtonComponent` from `@carbon/angular/combo-button`, and
  `MenuComponent` / `MenuItemComponent` (plus `MenuItemDividerComponent` where
  used) from `@carbon/angular/menu`.
- `cds-ng-combo-button` exposes the primary action handler as the `onClick`
  input, not as an output. Bind a function with `[onClick]="handler"`.
- Inputs are forwarded to the web component as properties, so use camelCase
  property bindings such as `[menuAlignment]`, `[tooltipAlignment]` and
  `[tooltipContent]`.
