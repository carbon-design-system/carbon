## Getting started

You can implement a data table in your project by importing the `TableComponent`
and using it along with any additional table components that you need.

The data table component needs two additional components to be provided:
`TableRowComponent` and `TableHeadComponent`. The `TableRowComponent`
(`cds-ng-table-row`) is the data you would like to display in the rows of your
table, whereas `TableHeadComponent` (`cds-ng-table-head`) specifies which table
column headings should be displayed.

```ts
import {
  TableComponent,
  TableHeadComponent,
  TableHeaderRowComponent,
  TableHeaderCellComponent,
  TableBodyComponent,
  TableRowComponent,
  TableCellComponent,
} from '@carbon/angular/data-table';

@Component({
  standalone: true,
  imports: [
    TableComponent,
    TableHeadComponent,
    TableHeaderRowComponent,
    TableHeaderCellComponent,
    TableBodyComponent,
    TableRowComponent,
    TableCellComponent,
  ],
  template: `
    <cds-ng-table>
      <cds-ng-table-head>
        <cds-ng-table-header-row>
          <cds-ng-table-header-cell>Name</cds-ng-table-header-cell>
          <cds-ng-table-header-cell>Status</cds-ng-table-header-cell>
        </cds-ng-table-header-row>
      </cds-ng-table-head>
      <cds-ng-table-body>
        <cds-ng-table-row>
          <cds-ng-table-cell>Load Balancer 1</cds-ng-table-cell>
          <cds-ng-table-cell>Disabled</cds-ng-table-cell>
        </cds-ng-table-row>
        <cds-ng-table-row>
          <cds-ng-table-cell>Load Balancer 2</cds-ng-table-cell>
          <cds-ng-table-cell>Starting</cds-ng-table-cell>
        </cds-ng-table-row>
        <cds-ng-table-row>
          <cds-ng-table-cell>Load Balancer 3</cds-ng-table-cell>
          <cds-ng-table-cell>Active</cds-ng-table-cell>
        </cds-ng-table-row>
      </cds-ng-table-body>
    </cds-ng-table>
  `,
})
export class MyComponent {}
```

After rendering a data table component using the code snippet above, you can
optionally add any number of features including sorting, row expansion,
filtering, row selection, and batch actions.

For more information, see each usage section below for the functionality that
you're interested in. If you want to see a full list of options, visit the
[component API](#component-api) section.

## Sorting

In order to sort the rows in your data table, you will need to use the
`[isSortable]="true"` property in the `cds-ng-table` component.

<Canvas of={DataTableSortingStories.Default} />

Optionally, you can add `[isSortable]="true"` to each `cds-ng-table-header-cell`
that you want to be sorted, or not sorted. This is useful if you only want to
enable sorting on some table column headers, but not all.

```html
<cds-ng-table-header-cell [isSortable]="true"> ... </cds-ng-table-header-cell>
```

### Programmatic sorting

You can also change the sort status of the table by querying the specific
`cds-table-header-cell` you would like to sort.

```js
// sorting the first column
document
  .querySelectorAll('cds-table-header-cell')[0]
  .shadowRoot.querySelector('button')
  .click();
```

### Custom sorting

If the default sorting logic doesn't match your use-case, you can use a custom
sort method.

`customSortRow` is a method that takes in the values of two cells, in addition
to some info, and should return -1, 0, or 1 as a result (mirroring the native
sort behavior in JavaScript).

The component uses a default `Intl.Collator` object created with the current set
locale to sort the rows. The default sorting row function uses this collator,
and as such it is needed in the custom sorting function.

For example, this `customSortRow` function would take on the following shape:

```ts
customSortRow(lhs: any, rhs: any, collator: Intl.Collator) {
  if (typeof lhs === 'number' && typeof rhs === 'number') {
    return lhs - rhs;
  }
  return collator.compare(lhs, rhs);
}
```

```html
<cds-ng-table [customSortRow]="customSortRow"> ... </cds-ng-table>
```

## Expansion

The `cds-ng-table` component supports row-level expansion when using the
`[expandable]="true"` property. Setting the property will apply the `expandable`
property to every row. In order to make a row be expandable, it is necessary for
the row to have a `cds-ng-table-expanded-row` component directly following it.

<Canvas of={DataTableExpansionStories.Default} />

In case you'd like a button to expand all the rows at once, you can use the
`[batchExpansion]="true"` property in `cds-ng-table`.

In case you only want to set specific rows to be expandable, be sure to set the
`[expandable]="true"` property only on that specific `cds-ng-table-row`
component, and have its adjacent sibling `cds-ng-table-expanded-row` directly
following it.

### Programmatic expansion

You can programmatically trigger a row expansion by querying the desired row:

```js
document
  .querySelectorAll('cds-table-row')[0]
  .shadowRoot.querySelector('.cds--table-expand__button')
  .click();
```

## Selection

The `cds-ng-table` component supports row selection when using the
`[isSelectable]="true"` property. Using `isSelectable` will automatically set a
numerical `selectionName` property to every row, though this can also be
customized with your own custom name.

## Filtering

Filtering in a `cds-ng-table` is provided through usage of the
`cds-ng-table-toolbar` and the `cds-ng-table-toolbar-search` component. Any
input entered through `cds-ng-table-toolbar-search` will be used in the built-in
filtering function.

```html
<cds-ng-table>
  <cds-ng-table-toolbar slot="toolbar">
    <cds-ng-table-toolbar-content>
      <cds-ng-table-toolbar-search
        placeholder="Filter table"></cds-ng-table-toolbar-search>
    </cds-ng-table-toolbar-content>
  </cds-ng-table-toolbar>
  <cds-ng-table-head> ... header </cds-ng-table-head>
  ... body and rows
</cds-ng-table>
```

### Multiple filters with batch updates

The filtering story shows an example of how to implement the

## Batch actions

You can combine batch actions with the `cds-ng-table` component to allow the
user to perform a single action on multiple selected rows.

This toolbar is highly customizable, as any action can be adhered to a
`cds-ng-button` and inserted into the toolbar.

In the example below, we have custom `cds-ng-button` components that we can
customize by using the `(click)` event and passing it any custom handlers.

The component has a built-in download function, that is called whenever one of
the `cds-ng-button` components has a `download` attribute. The component will
create a JSON object containing the currently selected rows, and trigger its
download within the browser.

### Overflow Menu

An overflow menu can be added to the toolbar table row. To add an overflow menu,
simply add a `cds-ng-table-cell` containing the `cds-ng-overflow-menu`.

```html
<cds-ng-table-row>
  <cds-ng-table-cell>Load Balancer 4</cds-ng-table-cell>
  <cds-ng-table-cell>HTTP</cds-ng-table-cell>
  <cds-ng-table-cell>443</cds-ng-table-cell>
  <cds-ng-table-cell>Round robin</cds-ng-table-cell>
  <cds-ng-table-cell>Mel's VM Groups</cds-ng-table-cell>
  <cds-ng-table-cell><cds-ng-link>Starting</cds-ng-link></cds-ng-table-cell>
  <cds-ng-table-cell>
    <cds-ng-overflow-menu [toolbarAction]="true" label="Options">
      <cds-ng-menu>
        <cds-ng-menu-item label="Stop app"></cds-ng-menu-item>
        <cds-ng-menu-item label="Restart app"></cds-ng-menu-item>
        <cds-ng-menu-item label="Rename"></cds-ng-menu-item>
      </cds-ng-menu>
    </cds-ng-overflow-menu>
  </cds-ng-table-cell>
</cds-ng-table-row>
```

## Accessibility Considerations

### Accessible Name

To comply with accessibility requirements, make sure to supply the component
with an accessible name by providing either the `aria-label`, `aria-labelledby`
or `title` attribute to the `Table` component. Read more on the accessible
naming rule
[here](https://able.ibm.com/rules/archives/latest/doc/en-US/aria_accessiblename_exists.html).
