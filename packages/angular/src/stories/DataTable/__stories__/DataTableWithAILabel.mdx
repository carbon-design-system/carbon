## Overview

The `cds-ng-table` component supports placing a `cds-ng-ai-label` in both the
column header and row.

<Canvas of={AILabelDataTableStories.AILabelWithSelectionAndExpansion} />

## AI Label anatomy

The `AI Label` itself is a button that acts as a `toggle-tip` trigger. To
construct the contents of the `AI Label` callout, you can place the desired
elements as a child of `cds-ng-ai-label`, like so:

```html
<cds-ng-ai-label size="mini" alignment="bottom-left">
  <div slot="body-text">Content Here</div>
</cds-ng-ai-label>
```

The `AI Label` also supports the rendering of an action bar at the bottom of the
callout. To achieve this, you can add elements with `slot="actions"` inside the
`slot="body-text"` element:

```html
<cds-ng-ai-label size="mini" alignment="bottom-left">
  <div slot="body-text">
    Content Here
    <cds-ng-icon-button kind="ghost" slot="actions" size="lg">
      <svg slot="icon" ...></svg>
      <span slot="tooltip-content"> View </span>
    </cds-ng-icon-button>
    <cds-ng-ai-label-action-button>View details</cds-ng-ai-label-action-button>
  </div>
</cds-ng-ai-label>
```

## Using `AI Label` in `DataTable`

### Using as a column header

To use a `AI Label` inside a column header, you'll need to add an
`cds-ng-ai-label` component to the appropriate `cds-ng-table-header-cell`.

```html
<cds-ng-table-header-cell>
  Attached groups
  <cds-ng-ai-label alignment="bottom-left">
    <div slot="body-text">Content Here</div>
  </cds-ng-ai-label>
</cds-ng-table-header-cell>
```

### Using in a row

To use a `AI Label` inside a `DataTable` row, you'll need to pass in your
`ai-label` component to `cds-ng-table-row`:

```html
<cds-ng-table-row>
  <cds-ng-ai-label alignment="bottom-left">
    <div slot="body-text">Content Here</div>
  </cds-ng-ai-label>
  <cds-ng-table-cell>Load Balancer 1</cds-ng-table-cell>
  <cds-ng-table-cell>HTTP</cds-ng-table-cell>
  ...
</cds-ng-table-row>
```
