## Overview

The `cds-ng-text-input` component enables users to enter free-form text data.
The type of text field used should reflect the length of the content you expect
the user to enter. The default text input is for short, one-line content.

### Importing

```ts
import { TextInputComponent } from '@carbon/angular/text-input';

@Component({
  standalone: true,
  imports: [TextInputComponent],
  template: `
    <cds-ng-text-input
      label="Label text"
      placeholder="Placeholder text"
      helperText="Helper text"></cds-ng-text-input>
  `,
})
export class MyComponent {}
```

## Component API

<ArgTypes of={TextInputStories.Default} />

### `labelText`

The visible label shown above the input field.

```html
<cds-ng-text-input label="First name"></cds-ng-text-input>
```

### `size`

Controls the height of the input field. Accepted values are `xs`, `sm`, `md`
(default), and `lg`.

```html
<cds-ng-text-input size="sm" label="Label"></cds-ng-text-input>
<cds-ng-text-input size="md" label="Label"></cds-ng-text-input>
<cds-ng-text-input size="lg" label="Label"></cds-ng-text-input>
```

### `type`

Sets the native `<input>` type attribute. Defaults to `text`. Use `password` to
mask characters, `email` to trigger email-specific keyboards, etc.

```html
<cds-ng-text-input type="password" label="Password"></cds-ng-text-input>
```

### `placeholder`

Descriptive placeholder text shown when the field is empty.

```html
<cds-ng-text-input
  placeholder="Enter your name"
  label="Name"></cds-ng-text-input>
```

### `invalid` and `invalidText`

Use `[invalid]="true"` together with `invalidText` to indicate a validation
error below the input.

```html
<cds-ng-text-input
  [invalid]="true"
  invalidText="Please enter a valid email address"
  label="Email"></cds-ng-text-input>
```

### `warn` and `warnText`

Use `[warn]="true"` together with `warnText` to display a non-blocking warning
message below the input.

```html
<cds-ng-text-input
  [warn]="true"
  warnText="This email is already registered."
  label="Email"></cds-ng-text-input>
```

### `readonly`

Prevents editing while displaying the current value.

```html
<cds-ng-text-input
  [readonly]="true"
  value="Read-only value"
  label="Label"></cds-ng-text-input>
```

### `disabled`

Prevents user interaction and renders the input in a visually muted state.

```html
<cds-ng-text-input [disabled]="true" label="Label"></cds-ng-text-input>
```

### `enableCounter` and `maxCount`

Set `[enableCounter]="true"` and `[maxCount]="n"` to show a character count
indicator inside the field.

```html
<cds-ng-text-input
  [enableCounter]="true"
  [maxCount]="100"
  label="Bio"></cds-ng-text-input>
```

## Angular-specific notes

- Import `TextInputComponent` from `@carbon/angular/text-input`.
- `TextInputComponent` implements `ControlValueAccessor`. Use `[(ngModel)]` or
  `[formControl]` directly on `cds-ng-text-input`.
- For the skeleton state, also import `TextInputSkeletonComponent`.
- Content projection is supported for the `label-text` and `helper-text` slots:

```html
<cds-ng-text-input>
  <span slot="label-text">Custom <strong>label</strong></span>
  <span slot="helper-text">Helper with a <a href="#">link</a></span>
</cds-ng-text-input>
```
