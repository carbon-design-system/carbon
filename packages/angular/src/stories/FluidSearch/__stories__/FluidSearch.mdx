## Overview

The `cds-ng-fluid-search` component provides a fluid search input variant
spanning the full width of its container.

### Importing

```ts
import {
  FluidSearchComponent,
  FluidSearchSkeletonComponent,
} from '@carbon/angular/fluid-search';

@Component({
  standalone: true,
  imports: [FluidSearchComponent],
  template: `
    <cds-ng-fluid-search labelText="Search" placeholder="Search...">
    </cds-ng-fluid-search>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidSearchComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-search [formControl]="searchControl" labelText="Search">
</cds-ng-fluid-search>

<!-- Template-driven forms -->
<cds-ng-fluid-search [(ngModel)]="searchQuery" labelText="Search">
</cds-ng-fluid-search>
```
