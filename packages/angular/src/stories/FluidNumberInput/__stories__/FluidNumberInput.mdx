## Overview

The `cds-ng-fluid-number-input` component provides a fluid variant of the number
input, spanning the full width of its container with specialized styling.

### Importing

```ts
import {
  FluidNumberInputComponent,
  FluidNumberInputSkeletonComponent,
} from '@carbon/angular/fluid-number-input';

@Component({
  standalone: true,
  imports: [FluidNumberInputComponent],
  template: `
    <cds-ng-fluid-number-input
      label="Label"
      [value]="50"
      [min]="0"
      [max]="100"
      [step]="1">
    </cds-ng-fluid-number-input>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidNumberInputComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-number-input [formControl]="numberControl" label="Quantity">
</cds-ng-fluid-number-input>

<!-- Template-driven forms -->
<cds-ng-fluid-number-input [(ngModel)]="quantity" label="Quantity">
</cds-ng-fluid-number-input>
```
