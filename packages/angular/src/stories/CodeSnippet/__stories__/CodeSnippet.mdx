## Overview

Code snippets are strings or small blocks of reusable code that are copyable.

### Importing

```ts
import {
  CodeSnippetComponent,
  CodeSnippetSkeletonComponent,
} from '@carbon/angular/code-snippet';

@Component({
  standalone: true,
  imports: [CodeSnippetComponent],
  template: `
    <cds-ng-code-snippet type="single" tooltipContent="Copy to clipboard">
      node -v
    </cds-ng-code-snippet>
  `,
})
export class MyComponent {}
```

## Inline

Inline code snippets are used for distinguishing a symbol, variable, function
name or similar small piece of code from its surrounding text.

## Multi-line

Multiple line code snippets are used for displaying code with more than one
line. They're shown in a block and useful for showing classes, functions, blocks
of styles and the like. There is an option to wrap the lines displayed if the
lines are longer than the container.

<Canvas of={CodeSnippetStories.Multiline} />
<Canvas of={CodeSnippetStories.MultilineWithLayer} />

## Single-line

Single line code snippets are used when showing code that fits on one line
without wrapping. Useful for calling out terminal commands, function
invocations, expressions etc.

<Canvas of={CodeSnippetStories.Singleline} />

## Skeleton state

You can use the `cds-ng-code-snippet-skeleton` component
(`CodeSnippetSkeletonComponent`) to render a skeleton variant of a code snippet.
This is useful to display while content in your code snippet is being fetched
from an external resource like an API.

## Angular-specific notes

- **Component import:**
  `import { CodeSnippetComponent, CodeSnippetSkeletonComponent } from '@carbon/angular/code-snippet'`
- The host element in DevTools will be `cds-ng-code-snippet` — this is the web
  component running under a prefixed tag (ADR 0020). There is no inner element.
- Inputs use camelCase property bindings, for example
  `[maxCollapsedNumberOfRows]="15"`, `[hideCopyButton]="true"` and
  `[wrapText]="true"`.
- The copy button description is set with the `tooltipContent` input.
- The projected text content is the snippet. Use `{{ text }}` interpolation
  without surrounding whitespace to avoid extra leading/trailing spaces in the
  copied value, or provide `copyText` explicitly.
