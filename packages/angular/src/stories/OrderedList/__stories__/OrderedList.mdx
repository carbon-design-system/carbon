## Overview

Lists are vertical groupings of related content. `cds-ng-ordered-list` renders a
numbered list of `cds-ng-list-item` children.

### Importing

```ts
import { ListItemComponent, OrderedListComponent } from '@carbon/angular/list';

@Component({
  standalone: true,
  imports: [OrderedListComponent, ListItemComponent],
  template: `
    <cds-ng-ordered-list>
      <cds-ng-list-item>Review pull requests</cds-ng-list-item>
      <cds-ng-list-item>Update dependencies</cds-ng-list-item>
    </cds-ng-ordered-list>
  `,
})
export class MyComponent {}
```

<ArgTypes of={OrderedListStories.Default} />

### `cds-ng-list-item`

| Input    | Type      | Description                                                                                                                    |
| -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `nested` | `boolean` | `true` if this list item is a child of a nested list. The ordered and unordered list set this automatically on their children. |
