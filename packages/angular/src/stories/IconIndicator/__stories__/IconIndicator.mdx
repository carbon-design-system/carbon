## Overview

The `cds-ng-icon-indicator` component is useful for communicating severity level
information to users. The shapes and colors, communicate severity that enables
users to quickly assess and identify status and respond accordingly.

### Importing

```ts
import { IconIndicatorComponent } from '@carbon/angular/icon-indicator';

@Component({
  standalone: true,
  imports: [IconIndicatorComponent],
  template: `
    <cds-ng-icon-indicator
      kind="succeeded"
      label="Succeeded"></cds-ng-icon-indicator>
  `,
})
export class MyComponent {}
```

## Kind

Icon indicators can take the form of failed, caution major, caution minor,
undefined, succeeded, normal, in-progress incomplete, not started, pending,
unknown, and informative.

## Size

Icon indicators have two size options 16 and 20. The default is 16.

## Compact mode

When the `compact` input is set to `true`, the icon indicator displays only the
icon with the label shown in a tooltip on hover/focus. This is useful when space
is limited or when you want to display multiple indicators in a space
constrained layout.

```html
<cds-ng-icon-indicator
  kind="succeeded"
  label="Succeeded"
  [compact]="true"></cds-ng-icon-indicator>
```

## Customizing the label

You can set a string to customize the label of the Icon indicator.

## Angular-specific notes

### Input names

Web component attributes are exposed as camelCase inputs on
`IconIndicatorComponent`, for example `icon-description` is bound as
`[iconDescription]`.
