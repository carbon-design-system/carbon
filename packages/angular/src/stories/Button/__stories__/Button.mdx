## Overview

Buttons are clickable elements that are used to trigger actions. They
communicate calls to action to the user and allow users to interact with pages
in a variety of ways. `Button` labels express what action will occur when the
user interacts with it.

### Importing

```ts
import { ButtonComponent } from '@carbon/angular/button';

@Component({
  standalone: true,
  imports: [ButtonComponent],
  template: `
    <cds-ng-button kind="primary" size="lg" (buttonClick)="onClick($event)">
      Save
    </cds-ng-button>
  `,
})
export class MyComponent {
  onClick(event: MouseEvent) {
    /* ... */
  }
}
```

[Migration guide](?path=/docs/introduction-migration--docs).

## Danger Button

The danger button has three different styles: primary, tertiary, and ghost.
Determining which danger button style to use will depend on the level of
emphasis you want to give to the danger action. Destructive actions that are
considered a required or primary step in a workflow should use the primary
danger button style. However, if a destructive action is just one of several
actions a user could choose from, then a lower emphasis style like the danger
tertiary button or the danger ghost button may be more appropriate.

## Icon-only Button

Icon buttons allow users to take actions, and make choices, with a single tap.
Icon buttons can take the form of Primary, Secondary, Tertiary, and Ghost but
most commonly will be styled as primary or ghost buttons. Icon only buttons do
not support Danger, Danger tertiary, or Danger ghost.

Provide `tooltipText` — this becomes the button's accessible label as well as
the tooltip shown on hover.

<Canvas of={ButtonStories.IconButton} />

## Set of Buttons

You can wrap two `cds-button` elements in a `cds-button-set` when an action
required by the user has more than one option. Always use a negative action
button (secondary) paired with a positive action button (primary) in that order.
Negative action buttons will be on the left. Positive action buttons should be
on the right. When these two types of buttons are paired in the correct order,
they will automatically space themselves apart.

## Component API

<ArgTypes of={ButtonStories.Default} />

### `kind`

Carbon has seven types of buttons: `primary`, `secondary`, `tertiary`, `ghost`,
`danger`, `danger-tertiary`, and `danger-ghost`. If no `kind` is specified, a
`primary` button will be rendered. For more information on when to use each
variant, see the
[usage guidelines](https://www.carbondesignsystem.com/components/button/usage#overview).

```html
<cds-ng-button kind="primary">Primary</cds-ng-button>
<cds-ng-button kind="secondary">Secondary</cds-ng-button>
<cds-ng-button kind="tertiary">Tertiary</cds-ng-button>
<cds-ng-button kind="ghost">Ghost</cds-ng-button>
<cds-ng-button kind="danger">Danger</cds-ng-button>
<cds-ng-button kind="danger-tertiary">Danger tertiary</cds-ng-button>
<cds-ng-button kind="danger-ghost">Danger ghost</cds-ng-button>
```

### `size`

Specifies the rendered size of the button. Valid values are `xs`, `sm`, `md`,
`lg`, `xl`, and `2xl`. The default is `lg`, matching `@carbon/react` and
`@carbon/web-components`.

```html
<cds-ng-button size="xs">Button</cds-ng-button>
<cds-ng-button size="sm">Button</cds-ng-button>
<cds-ng-button size="md">Button</cds-ng-button>
<cds-ng-button size="lg">Button</cds-ng-button>
<cds-ng-button size="xl">Button</cds-ng-button>
<cds-ng-button size="2xl">Button</cds-ng-button>
```

### `href`

Providing an `href` turns the button into an anchor element.

```html
<cds-ng-button href="https://www.carbondesignsystem.com" target="_blank">
  Carbon Design System
</cds-ng-button>
```

### `tooltipText`

Required for icon-only buttons. Sets both the visible tooltip and the
`aria-label` for accessibility.

```html
<cds-ng-button tooltipText="Add item" tooltipPosition="bottom">
  <!-- icon projected here -->
</cds-ng-button>
```

### `tooltipAlignment`

Controls where the tooltip caret is rendered relative to the button. Accepted
values are `left` (start), `''` (center, default), and `right` (end).

```html
<cds-ng-button [tooltipText]="'Add'" [tooltipAlignment]="'left'"
  >…</cds-ng-button
>
<cds-ng-button [tooltipText]="'Add'" [tooltipAlignment]="''">…</cds-ng-button>
<cds-ng-button [tooltipText]="'Add'" [tooltipAlignment]="'right'"
  >…</cds-ng-button
>
```

### `tooltipPosition`

Controls where the tooltip is positioned relative to the button. Accepted values
are `top` (default), `right`, `bottom`, and `left`.

```html
<cds-ng-button [tooltipText]="'Add'" [tooltipPosition]="'top'">…</cds-ng-button>
<cds-ng-button [tooltipText]="'Add'" [tooltipPosition]="'right'"
  >…</cds-ng-button
>
<cds-ng-button [tooltipText]="'Add'" [tooltipPosition]="'bottom'"
  >…</cds-ng-button
>
<cds-ng-button [tooltipText]="'Add'" [tooltipPosition]="'left'"
  >…</cds-ng-button
>
```

### `(buttonClick)`

Emitted when the button or inner `<a>` is clicked. The event payload is the
native `MouseEvent`.

```html
<cds-ng-button (buttonClick)="handleClick($event)">Click me</cds-ng-button>
```

## Angular-specific notes

- **Component import:**
  `import { ButtonComponent } from '@carbon/angular/button'` (use in standalone
  `imports: [ButtonComponent]` or `NgModule` `imports: [ButtonComponent]`)
- The host element in DevTools will be `cds-ng-button` — this is the web
  component running under a prefixed tag (ADR 0020). There is no inner element.
  The `cds-ng-*` prefix ensures `@carbon/angular` can coexist with
  `carbon-components-angular` on the same page without tag-registry conflicts.
- Radius is controlled via CSS custom properties that inherit through the shadow
  boundary, not via an `@Input()`. See the
  [web-components button docs](https://web-components.carbondesignsystem.com/?path=/docs/components-button--docs)
  for the full `--cds-button-radius` API.
