## Overview

The `cds-ng-select` component provides a standard dropdown menu for selecting a
single item from a list.

### Importing

```ts
import {
  SelectComponent,
  SelectItemComponent,
  SelectItemGroupComponent,
} from '@carbon/angular/select';

@Component({
  standalone: true,
  imports: [SelectComponent, SelectItemComponent, SelectItemGroupComponent],
  template: `
    <cds-ng-select labelText="Deployment region" helperText="Select region">
      <cds-ng-select-item value="us-south"
        >Dallas (us-south)</cds-ng-select-item
      >
      <cds-ng-select-item value="eu-de">Frankfurt (eu-de)</cds-ng-select-item>
    </cds-ng-select>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`SelectComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-select [formControl]="regionControl" labelText="Region">
  <cds-ng-select-item value="us-south">Dallas</cds-ng-select-item>
  <cds-ng-select-item value="eu-de">Frankfurt</cds-ng-select-item>
</cds-ng-select>

<!-- Template-driven forms -->
<cds-ng-select [(ngModel)]="selectedRegion" labelText="Region">
  <cds-ng-select-item value="us-south">Dallas</cds-ng-select-item>
  <cds-ng-select-item value="eu-de">Frankfurt</cds-ng-select-item>
</cds-ng-select>
```
