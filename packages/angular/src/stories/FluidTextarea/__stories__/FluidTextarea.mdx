## Overview

The `cds-ng-fluid-textarea` component provides a fluid multiline text input
variant spanning the full width of its container.

### Importing

```ts
import {
  FluidTextareaComponent,
  FluidTextareaSkeletonComponent,
} from '@carbon/angular/fluid-textarea';

@Component({
  standalone: true,
  imports: [FluidTextareaComponent],
  template: `
    <cds-ng-fluid-textarea
      label="Text Area label"
      placeholder="Placeholder text">
    </cds-ng-fluid-textarea>
  `,
})
export class MyComponent {}
```

## Angular-specific notes

### Forms integration (`ControlValueAccessor`)

`FluidTextareaComponent` implements `ControlValueAccessor`, supporting both
template-driven and reactive Angular forms:

```html
<!-- Reactive forms -->
<cds-ng-fluid-textarea [formControl]="bioControl" label="Bio">
</cds-ng-fluid-textarea>

<!-- Template-driven forms -->
<cds-ng-fluid-textarea [(ngModel)]="bio" label="Bio"> </cds-ng-fluid-textarea>
```
