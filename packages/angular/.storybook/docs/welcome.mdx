# `@carbon/angular`

Angular components for the
[Carbon Design System](https://carbondesignsystem.com), built as thin wrappers
over `@carbon/web-components`. Each Angular component registers its backing Web
Component under the real `cds-*` tag at import time — the wrapper's host element
IS the web component (ADR 0015). No separate registration step is required.

## Install

```bash
npm install @carbon/angular
# or
yarn add @carbon/angular
```

## Basic usage

**Standalone component (preferred):**

```ts
// my.component.ts
import { Component } from '@angular/core';
import { ButtonComponent } from '@carbon/angular';

@Component({
  selector: 'app-root',
  standalone: true, // optional on Angular 19+, where it is the default
  imports: [ButtonComponent],
  template: `<cds-button kind="primary" (buttonClick)="onClick($event)"
    >Click me</cds-button
  >`,
})
export class AppComponent {
  onClick(e: MouseEvent) {}
}
```

**NgModule (also supported):**

```ts
// app.module.ts
import { NgModule } from '@angular/core';
import { ButtonComponent } from '@carbon/angular';

@NgModule({
  imports: [ButtonComponent],
})
export class AppModule {}
```

```html
<!-- app.component.html -->
<cds-button kind="primary" (buttonClick)="onClick($event)">Click me</cds-button>
```

## Styles

Add the Carbon stylesheet to your `angular.json` styles array:

```json
"styles": ["node_modules/@carbon/styles/css/styles.css"]
```

## Migrating from `carbon-components-angular`

Import everything from `@carbon/angular`. If you are migrating an existing
`carbon-components-angular` application, see the
**[Migration guide](?path=/docs/introduction-migration--docs)**.
