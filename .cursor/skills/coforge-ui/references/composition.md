# Composition (Operate, Carbon)

2x grid. Tokens not taste. Impeccable **Operate** only: scanability over
expression. Do not import impeccable `bolder` / `delight` / glass.

## Hierarchy

- One `h1` per view. IBM Plex until type bench Pass (Anek named, not required
  this wave).
- Ink on bone for body. Coral-text links. Coral fill **lg primary only**.
- Fields and layer-01 stay IBM. Page never `#ffffff`.

## Layout

- Header 48px Carbon UI Shell. Content inset 16/32/48 — use spacing tokens, not
  magic px in specs (`$spacing-*`).
- Search is **in-job** (Venues), labelled; placeholder is not the label.
- Tiles: Base for facts; Clickable only when proto-spec has a hotspot. No Book
  on P09 tiles.
- Tags: Gray = verified protocol; Outline = unpublished. Not coral.

## States

Every screen-spec lists `default` plus the states the flow uses: `empty`,
`error`, `loading` (optional), `success`. P09 success includes dropping
unpublished.

## Commitment (P14)

Wrong vs right document pair must differ by **more than colour**: position,
label, size, and confirmation copy. Do not use age-coded “simplified” UI.

## Motion

Carbon standard. `prefers-reduced-motion`. No parallax. Skip custom motion until
specified.

## Figma vs CSS

IBM variable mode on kit instances. Overlay colour is proven in CSS; do not
rebind the library. Screenshot and say Skip for IBM-blue links in Figma.
